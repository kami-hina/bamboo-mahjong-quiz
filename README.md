# バンブー麻雀クイズ

索子（ソウズ）だけの手牌を見て、**何向聴か**、そして
**テンパイなら待ち牌 / テンパイでなければ向聴数が進む牌（受け入れ）** をすべて答えるスマホ向け Web アプリ。

https://kami-hina.github.io/bamboo-mahjong-quiz/

- 索子 1〜9（各 4 枚）から作れる手牌を **すべて列挙** して出題（13 枚なら 93,600 通り）
- 回答は「向聴数」＋「牌の複数選択」。向聴数と牌の組が完全一致で正解
- 正解表示では、待ち牌ごとの形（両面・カンチャン・ペンチャン・シャンポン・単騎・七対子）、
  受け入れ牌ごとの「引いたあとの向聴数」、手牌の分解（面子・雀頭・塔子・孤立牌）を表示
- 成績（正解／不正解）は端末の localStorage に保存し、「未出題だけ」「間違えた問題だけ」で出題できる
- 「調べる」タブで任意の手牌を入力して向聴数・待ち・受け入れを確認できる
- 静的ファイルのみ。GitHub Pages で動作

## ルール

- 牌は索子 1〜9 のみ（各 4 枚）。字牌・他の数牌はなし
- 一般形（4 面子 1 雀頭）と七対子（13 枚のときのみ）を判定。国士無双は字牌がないので対象外
- 4 枚使い切っている牌も「形としての待ち／受け入れ」に含め、解説で「4枚使い切り（純カラ）」と注記
- 手牌の枚数は 13 / 10 / 7 / 4 枚から選べる（10 枚 = 3 面子 1 雀頭、7 枚 = 2 面子 1 雀頭、4 枚 = 1 面子 1 雀頭）

## 全パターン数

| 枚数 | 手牌の数 | テンパイ | 1向聴 | 2向聴 |
| --- | --- | --- | --- | --- |
| 13 枚 | 93,600 | 40,872 | 52,184 | 544 |
| 10 枚 | 32,211 | 12,830 | 19,056 | 325 |
| 7 枚 | 6,030 | 2,478 | 3,528 | 24 |
| 4 枚 | 495 | 258 | 237 | 0 |

索子だけだと 3 向聴以上にはならない。

## 構成

| パス | 内容 |
| --- | --- |
| `index.html` | アプリ本体 |
| `mahjong.js` | 列挙・向聴数・待ち・受け入れ・分解の計算（ブラウザと Node で共用） |
| `data/hands.js` | 全手牌の答え（`tools/build.js` が生成。1 手牌 2 文字で向聴数と待ち／受け入れのビットマスク） |
| `tools/build.js` | `node tools/build.js` で `data/hands.js` を再生成 |
| `tiles/` | 牌画像 |
